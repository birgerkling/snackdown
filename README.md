# Snackdown!

An original food-themed arena game for the browser.

## Play

[Play Snackdown in your browser](https://birgerkling.github.io/snackdown/) — no GitHub or ChatGPT sign-in required.

## Controls

- WASD or arrow keys: move
- Mouse: aim; click or Space: attack
- E: Super; Q: Topping
- DualShock 4: left stick to move, right stick to aim, R2 to attack, R1 for Super, L1 for Topping

Solo, Ranked, Boss Fight, Training and seasonal events are included. Accounts and progression are saved locally in each browser; they do not sync between devices or website addresses.

## Hosting

In repository Settings > Pages choose Deploy from a branch, main, /docs, then Save. All game files and assets are under docs/. No build step or server is needed.
